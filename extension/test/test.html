9.1 本地联调

Chrome 加载已解压扩展程序，开启开发者模式
访问 chrome://extensions → 开启右上角"开发者模式" → 点击"加载已解压的扩展程序" → 选择 extension 目录
连接本地 SpringBoot 后端（localhost:8080）进行接口联调
启动后端服务 → 在 Options 设置页确认 API 地址为 http://localhost:8080 → 点击"测试连接"按钮验证
验证各状态 Popup 展示正确
测试 5 种状态：idle（初始）/ detecting（检测中）/ safe（安全）/ warning（风险）/ error（错误）。访问普通 HTTPS 网站点击检测，确认安全状态展示正常
验证 Content Script 页面信息采集完整
在 Service Worker 控制台执行测试脚本，验证 GET_PAGE_INFO 返回完整字段（url/title/text/html/domain/protocol/meta/forms）
验证高风险警告横幅正常注入与关闭
访问高风险网站 → 确认页面顶部出现红色警告横幅 → 点击"我知道了"按钮 → 确认横幅消失
验证 Service Worker 消息路由正常
运行 test-runner.js 的 testMessageRouting 测试组，验证所有 action 路由正确，type 字段向后兼容
验证缓存命中与未命中两种流程
首次检测某域名（缓存未命中 → 调用 API）→ 再次检测同域名（缓存命中 → 立即返回）。在 SW 控制台检查响应中 fromCache 字段

9.2 异常场景测试

网络错误 / API 超时处理
关闭后端服务 → 点击检测 → 确认 Popup 显示"网络连接失败，请检查后端服务是否启动" → 错误状态可重试
后端返回错误码时的 UI 展示
模拟后端返回 500/404 → 确认 Popup 错误状态正确展示 HTTP 状态码信息 → 不会白屏或卡死
采集超大页面时的性能测试（10万+字符）
访问大型新闻/文档页面（如长篇 Wikipedia）→ 点击检测 → 确认采集不卡顿、不崩溃。Content Script 已限制 text≤10000 字符、html≤500000 字符
不支持 chrome-extension:// 协议页面的优雅降级
打开 chrome://settings 或 chrome-extension://xxx 页面 → 点击扩展图标 → 点击检测 → 确认显示"当前页面协议不支持检测"，不会崩溃

自动化测试

运行 test-runner.js 自动化测试
以下测试可自动执行：消息路由、缓存机制、设备 ID、配置管理、历史记录、特殊协议页面、参数校验。
在 Service Worker 控制台（chrome://extensions → 扩展 → "Service Worker" 链接）中粘贴以下命令： 
importScripts('test/test-runner.js');
runAllTests();
或运行单个测试组： 
runTest('testMessageRouting');
runTest('testCache');
runTest('testDeviceId');
